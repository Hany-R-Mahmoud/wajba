# Team Decisions

This folder is the durable home for architecture, product/UX, API/data-contract, workflow, convention, deprecation, and migration decisions.

## Belongs Here

- settled architecture or integration choices
- API or data contract changes
- workflow and repository conventions
- deprecations and migrations
- important discussion outcomes

## Does Not Belong Here

- temporary chat
- unresolved brainstorming
- personal notes
- duplicated issue-tracker content

## How To Add A Decision

1. Copy `decision-template.md` for a substantial decision, or add a row to `decision-log.md` for a small one.
2. Use `Proposed`, `Accepted`, `Superseded`, or `Deprecated`.
3. Link related issues, PRs, docs, meetings, chats, or commits.
